# elanco-frontend-task
Elanco Frontend Task for Student Placement 2027

As requested by Elanco, I built a Minimum Viable Product (MVP) for a web application that brings tick sighting data to life, to help spread awareness and prevent tick-borne diseases.

I used HTML, CSS and JavaScript to build the code, Leaflet for the interactive map and severity markers (red, yellow and green), and LocalStorage API for the database, since I found it was easier to debug.

Core features I included were the interactive map, including features such as severity markers, filter controls, and the ability to view anywhere in the world. Another was a sidebar containing all sightings in further detail, showing location, the species, the date it was added and an add-on to show how recent it was added. I also included guides for each species which tells you what they're called as well as where to find them such as in certain areas or on animals. There is also a Report Sighting button where the user can select the species, severity, location and the exact coordinates and the option to add a photo of the area where they were found, all of which was supported by the LocalStorage API.

To run this file, clone this repository to your machine, run the application and double click 'index.html to open it to your default web browser.
